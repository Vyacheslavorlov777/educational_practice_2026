# Учебная практика 2026 — Проектирование и реализация БД

Проект выполнен на PostgreSQL + SQL. Состоит из 4 связанных заданий.

## Задание 1. Проектирование базы данных (3NF) и ER-диаграмма

Спроектированы 3 таблицы: `partners` (партнёры), `products` (товары,
вынесены отдельно, т.к. названия повторялись в продажах), `shipments`
(история отгрузок). Структура проверена на соответствие 1NF, 2NF, 3NF.

📁 [`Проектирование базы данных (3NF) и ER-диаграмма/`](./Проектирование%20базы%20данных%20(3NF)%20и%20ER-диаграмма/)

## Задание 2. Написание DDL-скрипта

Скрипт `schema.sql` создаёт все таблицы с PRIMARY KEY, FOREIGN KEY,
NOT NULL, UNIQUE и CHECK-ограничениями. Безопасен для повторного запуска
(`DROP TABLE IF EXISTS` в правильном порядке).

📁 [`Написание DDL-скрипта (База данных в коде)/`](./Написание%20DDL-скрипта%20(База%20данных%20в%20коде)/)

## Задание 3. Подготовка данных и импорт (ETL)

Исходные файлы `import_partners.csv` и `import_sales.txt` проанализированы,
найдены и исправлены проблемы: разные форматы дат, лишние пробелы,
повторяющиеся товары. Продажа с несуществующим `partner_id=4` не загружена
в базу (не нарушая FOREIGN KEY) и задокументирована. Результат — очищенные
файлы и `etl.sql`.

📁 [`Подготовка данных и импорт (ETL)/`](./Подготовка%20данных%20и%20импорт%20(ETL)/)

## Задание 4. Разработка проверочных SQL-запросов

3 запроса, покрывающих бизнес-требования: список партнёров, редактирование
партнёра, история отгрузок партнёра (JOIN трёх таблиц).

📁 [`Разработка проверочных SQL-запросов (Эмуляция бэкенда)/`](./Разработка%20проверочных%20SQL-запросов%20(Эмуляция%20бэкенда)/)

## ER-диаграмма из pgAdmin 4

Диаграмма построена в pgAdmin 4 (ERD Tool) по реальной структуре базы после
