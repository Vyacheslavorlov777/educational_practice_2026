# Задание 4. Разработка проверочных SQL-запросов

Файл `queries.sql` содержит 3 запроса, демонстрирующих, что база покрывает
бизнес-требования заказчика.

## Запрос №1 — список партнёров с количеством доставок

Возвращает данные партнёров (ID, название, ИНН, email, телефон, рейтинг),
отсортированные по названию компании, вместе с общим количеством сделанных
ими доставок. Используется `LEFT JOIN` (чтобы партнёры без единой доставки
тоже попали в список) и `COUNT` по `shipments.sale_id`.

## Запрос №2 — транзакция: новый партнёр + первая доставка

Демонстрирует добавление нового партнёра и записи о его первой тестовой
доставке в рамках одной транзакции `BEGIN ... COMMIT`. Если бы вторая
вставка (в `shipments`) провалилась, транзакцию можно откатить (`ROLLBACK`)
— партнёр не появится в базе без соответствующей доставки.

## Запрос №3 — история отгрузок партнёра за период

`JOIN` таблиц `shipments`, `partners` и `products` для детальной истории
отгрузок конкретного партнёра за указанный период: название товара, дата,
количество (в штуках) и итоговая сумма. Параметры `partner_id` и диапазон
дат заданы в `WHERE` (в примере — партнёр 1, март 2026), приложение
подставляет свои значения.
