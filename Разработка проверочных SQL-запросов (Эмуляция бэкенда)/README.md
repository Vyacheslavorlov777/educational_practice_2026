# Задание 4. Разработка проверочных SQL-запросов

Файл `queries.sql` содержит 3 запроса, демонстрирующих, что база покрывает
бизнес-требования из Задания 1.

## Запрос №1 — список партнёров

Возвращает все данные партнёров для отображения в приложении: ID, название,
ИНН, email, телефон, рейтинг.

## Запрос №2 — редактирование партнёра

Пример `UPDATE`, изменяющий телефон и рейтинг партнёра с `partner_id = 2`.
Первичный ключ (`partner_id`) не изменяется.

## Запрос №3 — история отгрузок партнёра

`JOIN` таблиц `shipments`, `partners` и `products` для получения полной
истории отгрузок конкретного партнёра: название партнёра, товар, дата,
количество, сумма. Параметр `partner_id` задан в `WHERE` (в примере — 1),
приложение подставляет своё значение.
